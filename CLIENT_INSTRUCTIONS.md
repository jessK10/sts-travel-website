# ✏️ How to Edit the STS Travel Website

Welcome! This guide explains how to update the website content using Notion.

---

## 🔑 Quick Summary

- **What you use**: Notion (a free app you already have access to)
- **What you can edit**: Text, headings, descriptions, phone numbers, images
- **How long it takes**: Changes appear on the website within **1 minute**
- **What you DON'T need**: No coding. No technical skills. No GitHub. No deployments.

---

## 📱 Where to Find Your Content

Open your Notion workspace. You'll see these databases:

| Database | What It Controls |
|---|---|
| 🏠 **Home Page** | The main landing page content |
| 📖 **About Page** | The "About Us" page content |
| 🛎️ **Services** | The list of services offered |
| 📞 **Contact Page** | Contact details and page text |

---

## ✍️ How to Edit Text

1. Open the database you want to edit (e.g., "Home Page")
2. You'll see a table with one row
3. Click on any cell to edit its content
4. Type your new text
5. That's it! The website will update within ~1 minute

---

## 🖼️ How to Change Images

Images are stored as **web links (URLs)**. To change an image:

1. Find a new image you want to use (e.g., on [Unsplash](https://unsplash.com))
2. Right-click the image → **"Copy image address"**
3. In Notion, find the image URL field (e.g., "Intro Image 1")
4. Paste the new image URL
5. The website will show the new image within ~1 minute

> **Tip**: Use high-quality images from [Unsplash](https://unsplash.com) — they're free and professional!

---

## 🛎️ How to Edit Services

The Services database has **one row per service**. To edit a service:

1. Open the **"Services"** database
2. Click on the row you want to edit
3. Change the **Name** (title) or **Description**
4. Don't change the **Icon Name** or **Slug** fields unless instructed

To **add a new service**:
1. Click **"+ New"** at the bottom of the database
2. Fill in: Name, Description, Icon, Icon Name, Order, and Slug
3. Ask your developer for help with Icon Name values

To **remove a service**:
1. Right-click the row → **"Delete"**

> **Note**: Changing the order of services? Update the **Order** number for each service.

---

## ⚠️ What NOT to Do

Please **do NOT**:

| ❌ Don't do this | Why |
|---|---|
| Delete a database | The website will fall back to default content |
| Rename property names (column headers) | The website won't find the content |
| Delete all rows from a database | Same as above |
| Add extra properties | They'll be ignored (harmless but unnecessary) |
| Change the database name | No effect, but keep it clear for yourself |

## 📊 Fields Reference

### Home Page
| Field | What It Does |
|---|---|
| Hero Title | Main heading on the hero section |
| Hero Description | Subtitle text on the hero |
| Hero Badge | Small label tag (optional) |
| Intro Short Name | Company short name (e.g., "STS") |
| Intro Description | The long paragraph in the intro section |
| Intro Image 1 / 2 | The two editorial photos |
| Stat 1–4 Value/Label | Statistics displayed below the intro |

### About Page
| Field | What It Does |
|---|---|
| Hero Title | Page hero heading |
| Founder Name/Title/Story | Founder section content |
| Founder Image | Photo of the founder |
| Tagline | The quote displayed on the page |
| Mission / Vision | Mission & Vision section text |

### Services
| Field | What It Does |
|---|---|
| Name | Service title |
| Description | Service description |
| Icon | Emoji displayed with the service |
| Order | Display order (1 = first, 2 = second, etc.) |

### Contact Page
| Field | What It Does |
|---|---|
| Hero Title | Page heading |
| Phone | Phone number displayed |
| Email | Email address displayed |
| WhatsApp | WhatsApp number for chat link |
| Address / City / Country | Office address |
| Business Hours | Working hours text |

---

## 🔄 How Updates Work

1. You make a change in Notion
2. The website checks for updates every **60 seconds**
3. Your change appears automatically — no action needed!

---

## 🆘 Need Help?

If something looks wrong on the website after making changes:
1. **Wait 2 minutes** — the update may not have refreshed yet
2. **Check the field name** — make sure you edited the right property
3. **Contact your developer** — they can troubleshoot from their end
